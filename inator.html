Inator Project

Descrition: For this project I was tasked to model, texture, and edit an inator based of the children’s tv show, “Phineas and Ferb.” The goal for this project was to have as much detail in the models as possible.
Programs: Autodesk Maya, Adobe Substance Painter, Adobe Photoshop

Modeling

The modeling for this project involved creating a highly detailed 3D model of the Inator, focusing on capturing the intricate design elements and ensuring proper proportions. While I was able to acheive the basic models by using basic shapes, getting the finer details was a challenge as it required a lot of time and effort.

Texturing

For the texturing, I used Adobe Substance Painter to create detailed materials and apply them to the 3D model. This allowed me to achieve a weathered look that enhanced the overall appearance of the Inator.

Aov's

The AOVs (Arbitrary Output Variables) were used to isolate different aspects of the rendering, allowing for more control over the final image composition.

Final Render

This is the final render for the Inator project. I took multiple renders so that you can see how detailed the model is.

Reflection

Overall, this project taught me a lot about the importance of attention to detail in 3D modeling and texturing. It also highlighted the significance of proper lighting and rendering techniques to achieve a visually appealing result.
