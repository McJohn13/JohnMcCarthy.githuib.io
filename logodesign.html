Logo Design

Descrition: This was a logo design that was submitted for a contest hosted by the Alfred State Agriculture and Veterinary Technology department. I had to use specific font and colors to meet the requirements set by the contest.
Programs: Adobe Ilustrator

Variations

First Prototype

The first version of this was meant to be a test to see what shapes work well. This was also meant to see which colors are going to be the primary, secondary, and accents colors.

Final Version

This is the final product. I changed the shape of it to make it more like a badge as this is going to be on clothing. I also switched the blues so the wording is more noticable.

Images

Reference Images

The animals and the grass used are all stock images. With the short time frame to make this logo, I felt it appropiate to use stock images as makeing them by hand would take too much time.

Reflection

This project taught me how to work within restrictions and be able to make something that looks appealing. It has also taught me how to apply crtisism to improve my work.
