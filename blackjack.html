Sunset Drive

Descrition: This was a semester long game that I made in Godot. My goal for this game was to make a blackjack game wit the design and feel of something that came out of the early 90's.
Programs: Godot

Variations

First Prototype

The first prototype was a simple version of the game with basic controls and a minimal design. This was just to get a layout for the game and how it would feel when playing.

Second Prototype

The second prototype was more of the same with the addition of a deck and cards that reflect what the player and dealer have.

Third Prototype

For the third prototype I added money to the game. This allows the player to gamble in the game.

Fourth Prototype

The fourth prototype all I added were a starting screen along with a rules page to explain how to play the game.

Final Product

The final product includes all the features and improvements from the previous prototypes. I did add animation to the cards so when dealt they go from the deck to either the player or dealer.

Code

Card Code

This is the code for the cards. What it does is pick a random suite based on the number that was sent from the player or dealer. Then it will travel to the desired position. It will then call a signal to let the game know that it is done animating.

Player Code

This is the player code. All this does is tell you what your score is.

Dealer Code

The dealer code is similar to the players code. Except for the timer that is used to make it feel like the dealer is actualy dealing cards.

Game Code

At the start of the game it hides the player actions so the player cannot play when they shouldn't. The process function is there to check if the player has busted and if the dealer is greatr than or equal to its limit. When That checks it will then go through another check to see if it should payout. The on_start_pressed function runs a check to see if any money is in the pot. If there isn't any it prompts you to, if there is it runs as usual.

The deal_card function is meant to deal two cards at the start to both player and dealer. It does this by running a while loop to deal the cards until it reaches the amount needed. This is connected to the next function which check to see if the player can do an action. The hit and stand functions are player actions that can be used to either ask for another card or end their turn.

The timer function is meant to sync up with the dealer and deal a new card every time the dealer's timer runs out. The double down function is the same as the hit function except it end the players turn. The plus and minus functions all do the same. They will add or subtract based on the value. They will also make sure to check if the player has enough money to add or remove from the pot.

This function resets the players and dealers counts, removes any cards in the scene, and asks the player if they want to play again.

Reflection

This project expanded my knowledge on how to make video games and implement various features in Godot. It also taught me how to make and use components in video games.
