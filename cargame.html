Sunset Drive

Descrition: This was a semester long game that I made in Unity. The game is a scenic driving game meant to be relaxing and fun.
Programs: Unity

Variations

First Prototype

The first prototype was a simple version of the game with basic controls and a minimal environment. This was a good starting point to test the mechanicas and get a feel for the engine.

Second Prototype

The second prototype was more of the same but with the addition of the road textures

Third Prototype

For the third prototype I added to the enviroment by adding grass to the sides of the road. It was also around this time that I started to implement the procedural generation for the road.

Final Product

The final product includes all the features and improvements from the previous prototypes. With the addition of trees to give the enviroment some variation. Also the fence create a border that prevents the player from leaving the intended area.
