Small Appliance Project

Descrition: This was a small project I had to do. The goal of this project was to model, texture, and render a small kitchen appliance.
Programs: Autodesk Maya, Adobe Substance Painter

Modeling

I started modeling the microwave by starting out with a basic cube. By extruding I was able to create many of the details of the microwave like the handle, the clock, the glass, and the vents on the side. Also, by using the bevel tool I was able to get a smoother edge on the outside while also getting a sharper edge when needed.

Texturing

All the textures were made by me in Adobe Substance Painter. I wanted to give it a used look. By using the Metal Edge Wear on a mask I was able to achieve that look.

This is the finished render.

Reflection

This project expanded my knowledge on how to make my own textures in Substance painter. This project also helped expand my modeling techniques.
